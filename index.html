About the sequence

If n is even, the next term is n / 2. If n is odd, the next term is 3n + 1. These plots follow that rule until the value is 1. The cycle 4 → 2 → 1 is not repeated.

The Collatz conjecture says every positive integer eventually reaches 1. It is still unproved. This page only draws the paths you enter.
